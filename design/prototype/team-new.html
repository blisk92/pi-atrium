On start what happens when you click Start
  • Each member gets a _pi-agents/agents/<id>/ folder with a .pi/SYSTEM.md persona file
  • Skills are loaded into a headless Pi sidecar per member
  • pi-intercom is initialized so members can talk to each other
  • Initial tasks are dispatched; the team's CWD becomes the work root
